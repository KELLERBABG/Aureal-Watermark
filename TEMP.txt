# Aureal Watermark — Pre-Release Technical & Architecture Checklist
Target Release: Production Drop / Public Release

---

## 1. Digital Signal Processing & Acoustic Hardening

- [x] Dynamic Psychoacoustic Masking (Silence & Pause Handling)
  - Issue: Constant carrier injection causes perceptible noise during quiet intros, vocal pauses, and acoustic breakdowns.
  - Task: Compute slot-level RMS energy in the host audio prior to carrier synthesis.
  - Fix: Attenuate the watermark amplitude proportionally when host RMS drops below -30 dBFS; mute the carrier during near-silence (<= -60 dBFS) to preserve clean quiet sections.

- [x] Headroom Protection & Soft-Peak Limiting
  - Issue: Direct float32 superposition (`pcm + wm`) can cause values to exceed 1.0 on masters near 0 dBFS, resulting in digital clipping when writing to 16/24-bit PCM.
  - Task: Scan peak amplitude post-superposition.
  - Fix: Automatically scale host audio down slightly if peak > 0.999 to guarantee a clean, clipping-free peak ceiling (<= 0.995).

- [ ] Resampling Invariance (Sample Rate Normalization)
  - Issue: `deriveGeometry()` computes slot and chip lengths strictly from input sample rates; watermarking at 48 kHz and downsampling to 44.1 kHz breaks template matching.
  - Task: Implement an internal resampling check in `detect.js` and `aural-watermark-verify.js`.
  - Fix: Resample incoming audio to a canonical rate (e.g., 44.1 kHz) before slicing and matched filtering.

---

## 2. Payload, Modulation & Synchronization

- [x] Enhanced Error Correction (Multi-Bit Recovery)
  - Issue: The 1-bit soft-decision flipping mechanism fails whenever lossy codecs or noise flip 2 or more bits across the 48-bit codeword.
  - Task: Expand recovery beyond single-bit brute force.
  - Fix: Implemented reliability-ordered 2-bit permutation sweep on the 8 lowest-confidence bits (28 trials) on CRC mismatch, deterministically repairing up to 2-bit burst errors.

- [ ] Stream Synchronization Preamble
  - Issue: Slicing cropped audio or mid-track snippets forces the detector to sweep a fractional offset grid across the entire frame length.
  - Task: Add a deterministic synchronization marker (e.g., a short 7-bit Barker sequence or chirp).
  - Fix: Run a fast 1D cross-correlation against the boundary marker to identify the exact frame start offset in a single pass.

## 3. UI, Runtimes & Workflow Tooling

- [x] Web Worker Offloading in Studio Demo
  - Issue: Running synchronous decoding and correlation on the main UI thread locks the browser tab when analyzing long or high-sample-rate audio files.
  - Task: Move `verifyAudioBuffer()` and `detectWatermark()` into a background `Worker`.
  - Fix: Implemented non-blocking background analysis with zero-copy buffer transfer and 60 FPS UI responsiveness in `demo/index.html` and `demo/verifier.html`.

- [x] Promo Leak Batch Script (`scripts/batch_distribute.js`)
  - Issue: The CLI currently processes single files, leaving the common "leak tracking" workflow unautomated.
  - Task: Build an automated distribution script.
  - Fix: Implemented batch script accepting a master audio file and recipient list, generating uniquely tagged copies and `recipients.json` mapping.

- [x] One-Click Forensic Audit Script (`scripts/audit_leak.js`)
  - Issue: Identifying leaked copies requires manual cross-referencing.
  - Task: Build an automated forensic leak auditor.
  - Fix: Implemented `scripts/audit_leak.js` that scans leaked WAV/MP3/M4A audio, extracts ID, and confirms match against `recipients.json`.
