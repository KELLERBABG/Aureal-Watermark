### Core DSP Parameters

| Parameter | Value / Implementation | Description |
| :--- | :--- | :--- |
| **Modulation Scheme** | Direct-Sequence Spread Spectrum (DSSS) | 48 BPSK symbols per repetition |
| **Codeword Structure** | 32 data bits + 16-bit CRC-16/CCITT-FALSE | $2^{32} = 4,294,967,296$ unique IDs |
| **Carrier Bands** | `High` (16.5–19.5 kHz)<br>`Mid` (8.0–13.0 kHz)<br>`Dual` (Both simultaneously) | Configurable frequency bands for lossy compression survival |
| **Window Shaping** | Continuous periodic Hann window | Zero DC offset, continuous phase transitions across chip boundaries |
| **Embedding Level** | $-24\text{ dB}$ to $-30\text{ dBFS}$ (nominal) | Scaled by `strength` parameter ($0.0 \le s \le 1.0$) |
| **Repetition Period** | ~1.0 second per frame | Integrates coherently over time ($S/N \propto \sqrt{N}$) |
| **Error Correction** | Reliability-ordered soft-decision 1-bit correction | Evaluates smallest soft-decision metrics on CRC mismatch |

## 2. Detection & Verification Pipeline

```
Input Audio ──► Multi-Channel Downmix ──► Frame Folding (Modulo Geometry)
                                                     │
                                                     ▼
Confidence Verdict ◄── Z-Score ◄── Soft Match ◄── Fractional Resync Grid
```

1. **Downmix & Normalization:** Multi-channel streams are downmixed to mono float32 samples.
2. **Frame Folding:** Audio samples are folded modulo the frame length ($L = \text{sampleRate} \times \text{frameDuration}$), accumulating energy coherently across repetitions while averaging out uncorrelated host audio.
3. **Resynchronization Search:** Evaluates fractional frame shifts ($\pm 1/16, \pm 2/16, \pm 4/16$) to eliminate phase drift introduced by lossy encoder padding or decimation filters.
4. **Matched Filtering:** Computes the dot product against keyed pseudorandom noise (PN) sequences generated by `makeSymbolStream()`.
5. **Statistical Z-Scoring:** Computes the verification confidence score:
   $$\text{confidence} = \text{clamp}\left(\frac{z - 3.0}{27.0}, 0.0, 1.0\right)$$
   Where $z = \frac{\mu - \mu_0}{\sigma / \sqrt{48}}$.
